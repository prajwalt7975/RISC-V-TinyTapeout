# RISC-V-TinyTapeout
Multi-cycle RISC-V processor designed using Verilog HDL, with RTL simulation and verification


RISC-V Tiny Tapeout

Overview

A multi-cycle RISC-V processor implemented using Verilog HDL. This project explores processor architecture, RTL design, and simulation-based verification.

Architecture

The processor uses a five-stage control sequence:

1. Fetch
2. Decode
3. Execute
4. Memory
5. Writeback

Features

- Verilog-based RTL implementation
- Multi-cycle processor architecture
- Instruction execution and data memory operations
- Simulation using a Verilog testbench
